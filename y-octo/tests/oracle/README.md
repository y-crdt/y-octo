# Yjs interoperability tests

Run from the project root with Node.js 22 or later. The pinned Yjs versions
generate the expected states and Update V1 bytes. Rust replays the checked-in
fixtures offline. Where versions differ, the reference is Yjs 13.6.33.

```sh
npm ci --prefix y-octo/tests/oracle --ignore-scripts
npm run check --prefix y-octo/tests/oracle
cargo test -p y-octo --test yjs_live_oracle --test yjs_concurrent_oracle
```

After an intentional fixture change, run `npm run generate --prefix y-octo/tests/oracle`.
Inspect a single record with `node y-octo/tests/oracle/unpack.mjs live.jsonl.gz live-map-1`.

## Operation traces

Each file in `y-octo/tests/traces` declares replicas, root types and ordered
steps. An edit targets a root followed by map keys or array indices. Text
positions count UTF-16 code units and array positions count elements. Sync
steps can select, reorder or repeat packets. Use the same type for a root
on every replica.

The online test sends updates in both directions and checks visible content,
item identities, state vectors, deletions and pending dependencies. To replay a
minimized failure, set `TRACE_INPUT` to the absolute path of its JSON file in
`target/trace-failures`.

```sh
cargo test -p y-octo --test trace_differential online_yjs_differential -- --ignored --exact
cargo test -p y-octo --test trace_differential replay_saved_trace -- --ignored --exact
```

Use `node y-octo/tests/oracle/regressions.mjs --import "$TRACE_INPUT"` to add
a regression with expectations generated by Yjs.

## Upstream replay

`check:upstream` fetches the pinned test sources and regenerates the full corpus
in `target/yjs-oracle`. The checked-in manifest and small vectors support offline
replay. Inspect exclusions with `node y-octo/tests/oracle/upstream.mjs --report`.
Reader limitations are registered in `upstream-known-failures.json`.

```sh
npm run check:upstream --prefix y-octo/tests/oracle
cargo test --release -p y-octo --test yjs_upstream_oracle replay_upstream_factory -- --ignored --exact
node y-octo/tests/oracle/upstream-exports.mjs
```

Run `node y-octo/tests/oracle/budget.mjs` to report fixture sizes.

To check raw update compaction across reopen and edit cycles, run
`cargo test -p y-octo --test trace_differential online_storage_chain -- --ignored --exact`.

Additional offline test targets include `yjs_undo_oracle` for scoped undo and redo and `yjs_local_oracle` for importing renderer edits.
